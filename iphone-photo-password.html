아이폰 사진에 비밀번호 거는 법 3가지, 폰 암호와 다른 비번은 한 곳뿐

2026-11-11 · 락박스 안내 글

사진 앱에는 사진마다 비밀번호를 거는 칸이 없습니다. 그래서 잠가 둔 줄 알았던 사진이 폰 암호를 아는 가족이나 연인 손에서 그대로 열리는 일이 생깁니다.

결론부터: 아이폰 기본 기능으로 사진을 잠그는 방법은 3가지입니다. 사진을 가리기 해서 '가려진 항목' 모음에 넣기, 메모에 사진을 넣고 사용자 설정 암호로 잠그기, 사진 앱에 Face ID 요구 걸기. 이 중 폰 암호와 다른 비밀번호를 쓸 수 있는 것은 메모 하나뿐입니다. 나머지 둘은 폰 암호를 아는 사람이면 열 수 있습니다.

1. 3가지 방법, 무엇으로 열리나

세 방법은 잠그는 범위와 여는 열쇠가 다릅니다. 누구에게서 사진을 지키려는지에 따라 고릅니다.

방법여는 열쇠폰 암호를 아는 사람잠기는 범위
가려진 항목 잠금Face ID, 폰 암호열 수 있음가린 사진만
메모 사용자 설정 암호메모 전용 암호(Face ID를 켜면 Face ID도)열 수 없음메모에 넣은 사진만
사진 앱 Face ID 요구Face ID, 폰 암호열 수 있음사진 앱 전체

폰을 잠깐 빌려주는 상황이라면 가려진 항목이나 앱 잠금으로 충분합니다. 폰 암호를 아는 사람에게서 지켜야 한다면 메모의 사용자 설정 암호나 따로 잠그는 금고가 필요합니다.

2. 방법별 설정 순서

방법 1. 가려진 항목에 넣고 잠그기

  1. 사진 앱에서 숨길 사진을 엽니다. 여러 장이면 보관함에서 선택을 탭하고 고릅니다.
  2. 메뉴 버튼을 탭한 뒤 가리기를 탭합니다. 사진이 '가려진 항목' 모음으로 옮겨집니다.
  3. 설정 → 앱 → 사진에서 Face ID 사용이 켜져 있는지 확인합니다. 기본으로 켜져 있습니다.
  4. 같은 화면에서 '가려진 항목' 앨범 보기를 끄면 모음 자체가 사진 앱에서 보이지 않습니다.

자세한 내용과 잠금이 풀리는 경우는 아이폰 가려진 항목 잠금, 켜도 열리는 4가지 경우 (Face ID 설정법)에 정리했습니다.

방법 2. 메모에 넣고 다른 비밀번호로 잠그기

  1. 설정 → 앱 → 메모 → 암호에서 사용자 설정 암호 사용을 고르고 메모 전용 암호를 정합니다.
  2. 메모 앱에서 새 메모를 만들고 사진을 첨부합니다. 첫 줄은 "메모 1"처럼 무난하게 씁니다. 첫 줄이 제목이 되어 잠가도 목록에 보이기 때문입니다.
  3. 오른쪽 위 더 보기 버튼을 탭한 뒤 잠그기를 누릅니다.
  4. 사진 앱으로 돌아가 원본을 삭제하고, '최근 삭제된 항목' 모음에서도 지웁니다.

메모 잠금의 한계는 아이폰 메모 잠금 방법, 잠가도 새어 나가는 4가지 경우에서 더 자세히 볼 수 있습니다.

방법 3. 사진 앱 자체를 잠그기

  1. 홈 화면에서 사진 앱 아이콘을 길게 터치합니다.
  2. 빠른 동작 메뉴에서 Face ID 요구를 탭합니다.
  3. 이제 사진 앱을 열 때마다 Face ID나 암호를 거칩니다. 잠긴 앱 안의 정보는 검색, Siri 제안, 알림 미리보기에도 보이지 않습니다.

다른 앱을 잠그는 방법과 잠가도 드러나는 곳은 아이폰 앱 잠금 방법, Face ID로 잠그고 숨겨도 드러나는 4곳을 참고하세요.

3. 비밀번호를 걸어도 드러나는 6가지 경우 점검표

  1. 폰 암호를 아는 사람: 가려진 항목과 앱 잠금은 Face ID가 실패하면 폰 암호로 열립니다. 폰 암호를 아는 사람에게는 잠금이 아닙니다.
  2. 원본이 그대로 남아 있다: 메모에 사진을 넣어도 사진 보관함의 원본은 지워지지 않습니다. 삭제한 사진도 '최근 삭제된 항목'에 30일 동안 남습니다.
  3. 다른 기기에서 열린다: iCloud 사진을 쓰면 같은 Apple 계정의 아이패드나 맥에서도 사진을 볼 수 있습니다. 그 기기의 잠금이 약하면 그곳이 빈틈이 됩니다.
  4. 앱 잠금은 그 기기에만 걸린다: 앱 잠금과 가리기 상태는 iCloud로 동기화되지 않습니다. 아이패드에서는 따로 걸어야 합니다.
  5. 메모는 한 번 열면 몇 분간 열려 있다: 잠긴 메모를 연 직후 폰을 건네면 다른 잠긴 메모도 열린 상태입니다. 건네기 전에 메모 목록 위 지금 잠금을 누릅니다.
  6. 이미 보낸 사본: 메시지, 공유 앨범, 클라우드에 한 번 보낸 사진은 폰의 잠금과 상관없이 받은 쪽에 남습니다.

마지막으로, 메모 전용 암호를 잊으면 애플도 잠긴 메모를 열어 주지 못합니다. 암호는 따로 기억해 둘 수 있는 것으로 정합니다.

4. 폰 암호와 다른 잠금을 따로 두려면

아이폰 기본 기능은 대부분 폰 암호가 마지막 열쇠입니다. 메모 잠금은 다른 암호를 쓸 수 있지만 제목이 드러나고, 동영상이 붙은 메모는 잠글 수 없습니다. 락박스는 서버 없이 아이폰 안에서만 사진과 동영상을 AES-256-GCM으로 암호화해 잠급니다. 아무도 못 열어요. 만든 사람도.

잠금은 3×3·5×5 패턴이나 PIN에 Face ID를 더해 씁니다. 비밀번호를 잊으면 한글 12단어 복구 문구로만 다시 열 수 있습니다. 무료로 10개까지 넣을 수 있습니다.

자주 묻는 질문

아이폰 사진 한 장 한 장에 비밀번호를 걸 수 있나요?

아니요. 사진 앱에는 사진마다 암호를 거는 기능이 없습니다. 가린 사진은 '가려진 항목' 모음 전체가 함께 잠깁니다.

가려진 항목에 폰 암호와 다른 비밀번호를 걸 수 있나요?

아니요. Face ID, Touch ID 또는 기기 암호로 열립니다. 다른 비밀번호가 필요하면 메모의 사용자 설정 암호나 별도 금고 앱을 씁니다.

메모에 사진을 넣으면 원본은 지워지나요?

아니요. 사진 보관함의 원본은 그대로입니다. 직접 삭제하고 '최근 삭제된 항목'에서도 지워야 합니다.

메모 전용 암호를 잊으면 어떻게 되나요?

애플도 잠긴 메모를 열 수 없습니다. 암호를 재설정해도 새 암호는 앞으로 잠글 메모에만 쓰입니다.
