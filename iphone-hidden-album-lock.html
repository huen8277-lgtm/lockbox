아이폰 가려진 항목 잠금, 켜도 열리는 4가지 경우 (Face ID 설정법)

2026-11-08 · 락박스 안내 글

가려진 항목에 Face ID를 걸어 두고 안심했다면 한 가지만 확인해 보세요. 폰 암호를 아는 사람은 그대로 열 수 있습니다.

결론부터: 설정 → 앱 → 사진(iOS 17 이하는 설정 → 사진)에서 Face ID 사용을 켜면 '가려진 항목'과 '최근 삭제된 항목' 앨범이 잠깁니다. iOS 16 이상에서 쓸 수 있습니다.

잠금 켜는 순서

  1. 설정 앱을 엽니다.
  2. iOS 18 이상은 맨 아래 앱으로 들어가 사진을 누릅니다. iOS 17 이하는 바로 사진을 누릅니다.
  3. Face ID 사용(Touch ID 기종은 Touch ID 사용, 둘 다 없으면 암호 사용)을 켭니다.

이제 사진 앱에서 가려진 항목을 열 때마다 인증을 거칩니다.

사진이 아니라 동영상을 숨기려면 → 아이폰 동영상 숨기기 방법

사진 앱을 통째로 Face ID로 잠그려면 → 아이폰 앱 잠금 방법, Face ID로 잠그고 숨겨도 드러나는 4곳

폰 암호와 다른 비밀번호로, 만든 사람도 못 여는 금고.
락박스는 사진을 서버에 올리지 않습니다.

앨범 자체를 목록에서 숨기기

같은 사진 설정 화면에서 가려진 항목 앨범 표시를 끄면, 사진 앱 목록에서 앨범이 아예 보이지 않습니다. 다시 보려면 이 스위치를 켜면 됩니다.

알아둘 한계

  • 잠금은 폰 잠금 암호로도 풀립니다. 폰 암호를 아는 사람에게는 소용이 없습니다.
  • iCloud 사진을 켜 두면 같은 계정의 다른 기기에서도 가려진 항목이 보입니다.
  • 사진 외에 신분증·메모 같은 자료는 정리할 수 없습니다.

폰 암호와 별개인 비밀번호가 필요하다면 별도 금고 앱이 맞습니다.

잠금이 풀리는 경우 점검표

잠금을 켰는데도 다른 사람이 가려진 항목을 볼 수 있다면 아래를 확인하세요.

확인할 것이유
폰 잠금 암호를 아는 사람이 있는지Face ID가 실패하면 폰 암호로 열 수 있습니다.
Face ID에 다른 사람 얼굴이 등록돼 있는지'대체 외모'로 등록된 사람도 열 수 있습니다. 설정 → Face ID 및 암호에서 확인합니다.
같은 계정의 아이패드·맥iCloud 사진을 쓰면 그 기기에도 가려진 항목이 있습니다. 그 기기의 잠금도 켜 두세요.
'가려진 항목' 앨범 보기켜져 있으면 숨긴 사진이 있다는 사실 자체가 드러납니다.

폰 암호와 다른 비밀번호가 필요할 때

가려진 항목 잠금은 결국 폰 잠금 암호와 같은 열쇠를 씁니다. 폰 암호를 가족이나 연인과 공유한다면 금고 앱처럼 따로 정한 비밀번호로 잠기는 곳이 필요합니다. 락박스는 폰 암호와 별개인 3×3·5×5 패턴이나 PIN으로 잠기고, 틀린 시도는 침입 기록으로 남습니다.

자주 묻는 질문

잠금을 켰는데 가려진 항목이 그냥 열려요.

iOS 16 이상인지 먼저 확인하세요. 그 다음 설정 → 앱 → 사진에서 Face ID 사용(또는 Touch ID 사용, 암호 사용)이 켜져 있는지 봅니다.

최근 삭제된 항목도 같이 잠기나요?

네. 같은 설정 하나로 '가려진 항목'과 '최근 삭제된 항목'이 함께 잠깁니다.

아이폰 기본 기능만으로 충분한 사람은 누구인가요?

폰 암호를 혼자만 알고, iCloud를 쓰는 다른 기기도 잘 잠가 둔다면 기본 잠금으로 충분합니다.
