아이폰 가려진 항목 앨범 잠그는 법 (Face ID·암호 설정)

2026-11-08 · 락박스 안내 글

결론부터: 설정 → 앱 → 사진(iOS 17 이하는 설정 → 사진)에서 Face ID 사용을 켜면 '가려진 항목'과 '최근 삭제된 항목' 앨범이 잠깁니다. iOS 16 이상에서 쓸 수 있습니다.

잠금 켜는 순서

  1. 설정 앱을 엽니다.
  2. iOS 18 이상은 맨 아래 앱으로 들어가 사진을 누릅니다. iOS 17 이하는 바로 사진을 누릅니다.
  3. Face ID 사용(Touch ID 기종은 Touch ID 사용, 둘 다 없으면 암호 사용)을 켭니다.

이제 사진 앱에서 가려진 항목을 열 때마다 인증을 거칩니다.

폰 암호와 다른 비밀번호로, 만든 사람도 못 여는 금고.
락박스는 사진을 서버에 올리지 않습니다.

앨범 자체를 목록에서 숨기기

같은 사진 설정 화면에서 가려진 항목 앨범 표시를 끄면, 사진 앱 목록에서 앨범이 아예 보이지 않습니다. 다시 보려면 이 스위치를 켜면 됩니다.

알아둘 한계

  • 잠금은 폰 잠금 암호로도 풀립니다. 폰 암호를 아는 사람에게는 소용이 없습니다.
  • iCloud 사진을 켜 두면 같은 계정의 다른 기기에서도 가려진 항목이 보입니다.
  • 사진 외에 신분증·메모 같은 자료는 정리할 수 없습니다.

폰 암호와 별개인 비밀번호가 필요하다면 별도 금고 앱이 맞습니다.
